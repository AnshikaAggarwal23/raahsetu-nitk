# Raahsetu
Project name: RaahSetu



Team: TechTonic



Team members: Anshika Aggarwal and Aditi Ailawadi



Problem statement: Women's safety in physical and digital environments, including rural communities.

Tech stack: React, Vite, JavaScript, Node.js, Express, and any other technologies actually used.



Setup instructions: How to run the frontend and backend.



Limitations: Clearly explain that some emergency and consent workflows are simulated.
